======================================================================

Batch tag

    confirm says the tag comes off the folder. After Confirm, the
    folder's OTHER files still have it (as their own tag)
[ ] Batch YES on files whose folder has a no for that tag: confirm says
    the folder's no comes off. After Confirm, the folder's other files

Folder tag
[ ] Add a folder tag to a folder where some files are marked no for it
    (or for a tag it implies): confirm lists them, "Clear noes on N

    and the files have the tag. Coverage seconds are kept

Tag links (Tag Manager → a tag → Also tags as)

    says the folder's no for B comes off. (This used to be refused.)

    confirm says that file's no is cleared; after, it has B
[ ] Folder has a no for B; a file in it has its own tag A. Link A → B:
    confirm says that file loses A; after, A is gone
[ ] Each of these is ONE undo step: ⌘Z puts everything back
[ ] A link that clashes with nothing still gets the plain confirm

The one conflict left: files moved in outside the app
