Everything since 0.4.0 has been built but not tested in the app.
Tick each box as you go. Note anything odd next to the item.

Tip: test on a COPY of a library, not the real one.

1. FOLDER NOES  (Browse → folder panel)
======================================================================

[ ] The Folder Tags section has its own separate input for noes,
    next to the input for folder tags
[ ] Adding a folder no shows it as a reddish pill, in its own group,
    set apart from the folder's tags
[ ] A no on a tag that files in the folder have as their OWN tag shows
    a confirm listing the files that will lose it
[ ] Confirming removes those tags from the files
[ ] Afterwards, adding that tag to a file in the folder is refused,
    with a short note in the file view
[ ] A no also follows implications back to the source: "not cat"
    removes an own "kitten" too, and the confirm gives the reason
[ ] Typing a folder TAG that is currently a folder NO (or the other
    way round) swaps it: the pill jumps groups and glows briefly
    - no confirm, unless files would lose tags
[ ] A folder can't contradict itself: folder tag "kitten" + folder
    no "cat" is refused with a message
[ ] Removing a folder no sends its files back to undecided for that
    tag (no leftover noes)
[ ] New files that land in the folder later inherit its noes

7. UNDO / REDO: THE BASICS
======================================================================

[ ] ⌘Z (outside a text field) undoes the last change and shows a
    toast at the bottom: "Undid: …"
[ ] ⇧⌘Z redoes it: "Redid: …"
[ ] With nothing to undo, the toast says "Nothing to undo"
    ("Nothing to redo" for ⇧⌘Z)
[ ] Pressing ⌘Z several times quickly steps back one change per press,
    with one toast that updates rather than a stack of toasts
[ ] Making a new change after undoing throws away the redo steps
[ ] In a text field (tag input, search, rename), ⌘Z still undoes
    TYPING, not app data
[ ] Undo never switches views or opens anything
[ ] Edit menu → Undo / Redo do the same as ⌘Z / ⇧⌘Z

8. UNDO: EVERY KIND OF CHANGE
======================================================================

For each item: do it, ⌘Z (it's fully reversed and the toast names it),
then ⇧⌘Z (it's back).

Tags on files
[ ] Add / remove a tag in the file view
[ ] Toggle a tag with the tag pointer (Space)
[ ] Toggle the upper tag in a pass (V)
[ ] Batch Tag YES on several files with several tags → ONE undo step
[ ] Batch Tag NO with several tags → ONE undo step
[ ] × on a no in the file view (reset to undecided) - the no, pass no
    and seconds all come back
[ ] Pass no (3) and taking it back

Folders
[ ] Add / remove a folder tag
[ ] Add / remove a folder no, and a yes↔no swap
[ ] A folder no that removed files' own tags: undo gives the tags back
[ ] Set / remove a folder metadata field
[ ] Change / remove a folder's profile picture
[ ] Rename a folder (files and sidebar follow both ways)
[ ] Create a folder (undo removes it, but only while it's still empty)
[ ] Delete a folder, "move files to Unsorted" mode: undo puts the
    folder AND its files back
[ ] Delete a folder, "trash" mode: undo brings the folder and files
    back with their tags and scores

Files
[ ] Move files to another folder (sidebar drag, filing, Browse drop)
[ ] Move with the 3-choice dialog ("move all"): undo restores the
    files' location AND the removed tags
[ ] Files dragged in from Finder: undo moves them back where they came
    from (same drive only)
[ ] Delete one file: it comes back with its tags and score
[ ] Delete several files at once → ONE undo step
[ ] Delete from the scroll / file view
[ ] Rotate: undo brings back the exact original (not re-rotated)
[ ] Replace file: undo brings the old version back

Compare
[ ] W and ↑ no longer undo anything
[ ] ⌘Z after a pick: scores go back AND that matchup returns on screen
    (focus, king and placement state too)
[ ] ⇧⌘Z after that: the pick is reapplied and Compare moves on
[ ] A placement match undoes the same way
[ ] Undoing a pick from ANOTHER view only changes scores (no jump to
    Compare)

Tag Manager
[ ] Create a tag
[ ] Rename a tag; move it to another category
[ ] Merge two tags (undo splits them back, files/folders as before)
[ ] Delete a tag (undo brings it back on all its files and folders)
[ ] Add / remove an implication (kitten → cat)
[ ] Create / edit / delete a category
[ ] Toggle "available in the tag pointer" for a tag and a category
[ ] Reorder tags by dragging → ONE undo step per drop

Other
[ ] Save / update / rename / delete a feed
[ ] Remove missing files (purge)

Not in the history (these should NOT be undone)

[ ] Saved pass progress
